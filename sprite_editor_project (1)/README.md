# Editor de Sprites 8-bits (Flet)

Proyecto de Electrónica Digital - Ingeniería de Sistemas - CUL

## Requisitos
- Python 3.x
- Flet: `pip install flet`

## Ejecución
```
python sprite_editor.py
```

## Descripción
Aplicación de escritorio que simula un editor de sprites de 8x8 píxeles,
con conversión bidireccional entre el estado visual de la cuadrícula y
un código hexadecimal de 64 bits.
